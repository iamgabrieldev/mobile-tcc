# 🚀 Guia Rápido - Novas Funcionalidades

## ✅ O que foi adicionado?

### 1. 🏆 Ranking de Usuários
Compete com outros usuários e veja quem está reduzindo mais CO₂!

**Como usar:**
- Toque na aba "Ranking"
- Veja sua posição
- Escolha período: Geral, Semanal ou Diário

### 2. 🤖 Análise por IA (Gemini Pro)
Receba análise personalizada dos seus hábitos com inteligência artificial!

**Como usar:**
1. Vá em "Perfil"
2. Toque em "Analisar Meus Hábitos"
3. Aguarde alguns segundos
4. Veja suas recomendações personalizadas!

**Para análises avançadas:**
- Configure sua API Key do Gemini
- Toque em "Configurar API Key" no perfil
- Obtenha a chave em: https://makersuite.google.com/app/apikey

### 3. 🌳 Cálculo de Árvores
Veja quantas árvores você precisaria plantar para compensar suas emissões!

**Onde ver:**
- Tela de Perfil
- Calcula automaticamente baseado em suas emissões

### 4. ⭐ Sistema de Pontos
Ganhe pontos reduzindo suas emissões de CO₂!

**Como funciona:**
- Reduziu emissões? Ganha 10 pontos por kg de CO₂
- Aumentou? Perde 5 pontos por kg de CO₂
- Manteve igual? Ganha 1 ponto por participação

**Onde ver seus pontos:**
- Tela de Perfil
- Tela de Ranking

### Passo 1: Registre suas emissões
```
Início → Registrar → Preencha os campos → Salvar
```

### Passo 2: Veja seus pontos
```
Perfil → Veja suas estatísticas
```

### Passo 3: Confira o ranking
```
Ranking → Veja sua posição
```

### Passo 4: Obtenha análise por IA
```
Perfil → Analisar Meus Hábitos
```

## 🎯 Dicas para Ganhar Mais Pontos

1. **Registre diariamente** - Mantenha o histórico consistente
2. **Reduza transporte** - Use transporte público ou bicicleta
3. **Economize energia** - Desligue aparelhos não usados
4. **Compare períodos** - Tente reduzir em relação ao dia anterior
5. **Siga as recomendações da IA** - São personalizadas para você!

## 🔧 Configuração Opcional

### API Key do Gemini (Recomendado)
Para análises mais detalhadas:

1. Acesse: https://makersuite.google.com/app/apikey
2. Crie uma API Key
3. No app: Perfil → Configurar API Key
4. Cole a chave e salve

**Sem API Key:**
- App funciona normalmente
- Análises básicas disponíveis
- Sem análises personalizadas por IA

## 📊 Entendendo os Números

### Pontos
```
Redução de 5 kg CO₂ = 50 pontos
Aumento de 2 kg CO₂ = -10 pontos
Sem mudança = 1 ponto
```

### Árvores
```
1 árvore absorve ~22 kg CO₂/ano
Suas emissões ÷ 22 = Árvores necessárias
```

### Ranking
```
Mais pontos = Melhor posição
Rankings resetam:
- Diário: Todo dia à meia-noite
- Semanal: Toda segunda-feira
- Geral: Nunca
```

## ❓ Perguntas Frequentes

**P: Como ganho pontos?**
R: Registrando suas emissões e reduzindo-as ao longo do tempo.

**P: Preciso da API Key?**
R: Não, mas ajuda a ter análises mais personalizadas.

**P: Como vejo minha posição no ranking?**
R: Na tela de Ranking, seu card aparece destacado.

**P: Quantos pontos preciso para ficar em 1º?**
R: Depende dos outros usuários! Continue reduzindo suas emissões.

**P: As análises da IA são gratuitas?**
R: Sim! O Google Gemini tem tier gratuito suficiente para uso pessoal.

**P: Posso perder pontos?**
R: Sim, se suas emissões aumentarem em relação ao registro anterior.
