# Assets

Esta pasta contém os assets do aplicativo (ícones, imagens, etc.).

## Arquivos necessários:

- `icon.png` - Ícone do aplicativo (1024x1024px)
- `splash.png` - Tela de splash (1242x2436px)
- `adaptive-icon.png` - Ícone adaptativo Android (1024x1024px)
- `favicon.png` - Favicon para web (48x48px)

## Sugestões de design:

- Use tons de verde (#4CAF50) para representar sustentabilidade
- Inclua elementos relacionados a folhas, planeta Terra ou ecologia
- Mantenha um design simples e moderno

## Gerando assets:

Você pode usar ferramentas online como:
- https://appicon.co/
- https://www.figma.com/
- https://www.canva.com/

Ou criar assets temporários com:
```bash
# No diretório raiz do projeto
npx expo install expo-splash-screen
```
