# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2024-10-03

### Adicionado
- ✨ Sistema de autenticação com Firebase
- ✨ Registro de consumo diário (transporte, energia, gás)
- ✨ Cálculo automático de pegada de carbono baseado em fatores IPCC 2023
- ✨ Tela inicial com resumo de emissões
- ✨ Relatórios com gráficos comparativos mensais
- ✨ Sistema de dicas personalizadas
- ✨ Exportação de dados em PDF
- ✨ Exportação de dados em CSV
- ✨ Armazenamento local de dados (até 24 meses)
- ✨ Interface moderna e responsiva
- ✨ Navegação por tabs

### Fatores de Emissão Implementados
- 🚗 Transporte Terrestre (6 tipos de veículos)
- ✈️ Transporte Aéreo (voos nacionais e internacionais)
- ⚡ Energia Elétrica (média Brasil)
- 🔥 Gás (GLP e Gás Natural)

### Documentação
- 📝 README completo com instruções
- 📝 Guia de configuração detalhado (SETUP.md)
- 📝 Guia de contribuição (CONTRIBUINDO.md)
- 📝 Documentação de código

### Segurança
- 🔒 Autenticação segura via Firebase
- 🔒 Verificação de e-mail obrigatória
- 🔒 Armazenamento local criptografado
